# Medusa Naga · video

0:15 · Real-time 3D · Web Audio · speech synthesis · one HTML file

A 15-second talking ad for InstaLanding: a 3D snake-tailed Medusa in sunglasses waves, sways and speaks her lines in a synthesized voice, then stays live, watching your cursor, reacting when tapped and spinning when dragged.

![Medusa Naga](preview.jpg)

**Watch it:** [instalanding.ai/videos/medusa-naga](https://instalanding.ai/videos/medusa-naga) — or open `index.html` from disk. Every frame renders live in the browser; there is no video file. Press play inside it (browsers only start sound after a click).
