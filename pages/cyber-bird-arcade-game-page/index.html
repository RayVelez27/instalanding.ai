01 — The build

Small game.
Big launch.

Every pixel on this page is drawn by code at runtime — the truck, the rockets, the smoke, the skies. No sprites to download, nothing to wait for.

Flight model

Hover-jets,
hard angles.

Every tap fires twin wheel-jets and a lungful of smoke. The truck noses up on the climb and tilts into the fall — readable, fair, and unforgiving.

Drop-in

One call
to embed.

The game mounts into any element, cleans up after itself, and exposes a tiny API for state, score and theme.

const game = CyberBird('container', {
  difficulty: 'hard',
  theme: 'dawn'
});

game.getBestScore(); // → 27
game.destroy();      // back to zero

Pilot notes
  1. Short taps beat panic. One boost lifts you about a truck-length — chain them, don't spam them.
  2. Aim for the middle. The next gap can only drift so far, so centered flight leaves room either way.
  3. Watch the nose. The truck tilts with your velocity — when it dips past level, it's time.
  4. Ten is a battery. Every 10 points charges 25%. Forty is a full pack.
