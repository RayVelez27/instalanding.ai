Try it now

  1. Drop

    Drag a file, a folder or a whole drive onto Tarn. It checks every byte while it climbs.

  2. Choose who

    Add a few emails or copy a link. Set a password, a download limit and an end date.

  3. They receive

    No account and no app: a clean page with a preview and one button.

    On the end date the files are wiped. You get a receipt, not a leftover.
