          What does an agent actually do?
          
          It takes a goal, writes a plan, then works through it with the tools you allow: querying data, reading documents, drafting, filing tickets. It checks its own work and reports back every six minutes.
          
        
          
        
          
          Will it do things without asking?
          
          Only the things you say it can. Anything you mark as irreversible, like sending email or changing a record, waits for a person to approve it in Slack or in the inspector.
          
        
          
        
          
          What can it connect to?
          
          Forty connectors cover the usual warehouse, docs, chat, CRM, ticketing and code tools. Anything with an API can be added as a custom tool.
          
        
          
        
          
          How is it secured?
          
          Undertow is SOC 2 Type II audited, supports SSO and SCIM on Enterprise, and encrypts data in transit and at rest. Each tool connection uses scoped credentials you can revoke at any time.
          
        
          
        
          
          What happens to our data?
          
          Runs execute in your workspace, nothing is used for training, and every step is logged with the inputs it saw so you can audit or replay it.
