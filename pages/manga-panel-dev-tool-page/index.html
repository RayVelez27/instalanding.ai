Got questions?

    

      

        
Reader mail

        
Straight answers to what developers ask before their first deploy.

      

      

        

          Q.01Do I have to rewrite my app?
          
Nope. OVERCLOCK auto-detects 60+ frameworks and runtimes. Already have a Dockerfile? We'll use it as-is. You only touch config if you want to override something.

        

        

          Q.02Will it replace my existing CI?
          
Only if you want it to. Run oc deploy as a step inside GitHub Actions or GitLab CI, or let OVERCLOCK handle builds on every push by itself.

        

        

          Q.03How safe is the shared build cache?
          
Cache entries are content-addressed, encrypted at rest and isolated per organization. Nothing is ever shared between teams, and you can purge it any time.

        

        

          Q.04Can I roll back by hand?
          
Any time. oc rollback swaps back to any of your last 100 releases in seconds with zero downtime, on top of the automatic rollback when error rates spike.

        

        

          Q.05Where does my code actually run?
          
Across 38 edge regions by default. On the Final Form plan you can pin workloads to specific regions to meet data-residency requirements.

        

        

          Q.06Is the free tier really free?
          
Yes. Three projects, preview deploys and the shared cache, with no credit card. Upgrade only when you outgrow it.
