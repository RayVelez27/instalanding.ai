11 · faq

FAQ

Glass <details> rows: the question on one line with a plus that turns into a cross, the answer in quiet grey below.

Does Arcline train models on my data?

No. Your data is only used to answer your team's questions and run your agents. It is never used to train Arcline's or any provider's models.

Which AI models can I use?

Arcline works with the major commercial model providers and open-weight models you host yourself. You can set a default and override it per assistant or per agent.

How are permissions handled?

Arcline mirrors the access controls of each connected source, so people only get answers drawn from documents they could already open.

Where is my data stored?

Choose a US or EU region when you create a workspace. Enterprise customers can also deploy Arcline inside their own cloud account.

Can agents take actions without approval?

Only if you allow it. Each agent action can be set to run automatically, require approval, or be disabled entirely.
