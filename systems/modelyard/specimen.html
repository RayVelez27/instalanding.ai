Quickstart

SWAP ONE URL. KEEP YOUR CODE.

The gateway speaks the chat format you already send. Name a route, state a policy, and every response tells you which model answered and what it cost.

  • →Drop-in for the SDKs you use today
  • →Policies live on the route, not in your code
  • →Per-request cost and model in the response headers
POST /v1/chat 
curl https://api.modelyard.example/v1/chat \
-H "Authorization: Bearer $MODELYARD_KEY" \
-d '{
  "route": "support-bot",
  "policy": ["cost", "eval>70"],
  "failover": true,
  "messages": [{"role": "user", "content": "Hi"}]
}'

# x-modelyard-model: yard-4-mini
# x-modelyard-latency-ms: 92
# x-modelyard-cost-usd: 0.00041
